## 📖 Overview

This repository houses the source code for a modern portfolio website built around a sophisticated "Glassmorphism" and "Bento Grid" aesthetic. The primary objective is to present technical credentials, project achievements, and continuous learning milestones in an engaging, cinematic, and responsive manner.

The portfolio heavily emphasizes a seamless user experience using vanilla web technologies without relying on heavy frontend frameworks, ensuring maximum performance and zero-dependency deployments.

## ✨ Key Features

- **Cinematic Hero Area**: Features dynamic, interactive code snippets (Excel, SQL, Python, Cloud Terminal) and ambient cursor glow effects.
- **Bento Grid System**: Clean, modular layouts for showcasing certifications, technical vaults, and data domains.
- **Progressive Disclosure**: Advanced accordion and tab systems to cleanly organize 50+ official achievements and learning paths.
- **Magnetic Micro-Interactions**: Custom physics applied to core buttons for an enhanced tactile feel.
- **Native Internationalization**: Built-in, zero-dependency EN/ID language toggling.

## 🛠️ Tech Stack & Architecture

This project is built using a lightweight, highly optimized Vanilla stack:

- **HTML5**: Semantic markup structuring the content hierarchy.
- **CSS3**: Advanced features including CSS Grid, Flexbox, native CSS Variables (HSL tokens), Backdrop Filters, and Keyframe Animations.
- **JavaScript (ES6+)**: Modularized logic handling Intersection Observers, dynamic DOM manipulation, and interactive effects.

### 📂 Repository Structure

The repository has been architected for scalability and clear separation of concerns:

```text
.
├── README.md             # Project documentation
├── index.html            # Main entry point and structural markup
└── assets/               # Core assets directory
    ├── css/              # Modularized styles
    │   ├── main.css      # Aggregator stylesheet
    │   ├── base.css      # CSS variables, resets, and ambient effects
    │   ├── layout.css    # Core structural elements (nav, footer, grids)
    │   └── components.css# Isolated UI components (cards, accordions)
    ├── js/               # Modularized logic
    │   ├── main.js       # App initialization and DOM binding
    │   ├── data.js       # Data structures (e.g., snippet libraries)
    │   └── animations.js # Scroll handling and cursor physics
    ├── img/              # Optimized graphical assets and badges
    └── data/             # Static JSON credentials and meta files
```
